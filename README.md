# Zombie Defense

Веб-игра в жанре Tower Defense на Python и Oracle PL/SQL.

Игрок выбирает карту, строит и улучшает башни, защищает базу от волн зомби, смотрит историю партий и общий рейтинг игроков. Основная игровая логика находится в Oracle PL/SQL, а Python отвечает за веб-сервер, HTML-интерфейс и обмен данными с базой.

## Стек

- Python 3
- Oracle Database
- SQL
- PL/SQL
- HTML
- CSS
- JavaScript

## Состав проекта

Основные файлы проекта:

- `zombie_defense_web.py` - веб-версия игры, HTTP-сервер и интерфейс.
- `requirements.txt` - Python-зависимости.
- `start_game.bat` - удобный запуск на Windows.
- `install.sql` - общий SQL-скрипт установки.
- `README.md` - описание проекта и инструкция по запуску.

SQL-файлы:

- `sql/01_schema.sql` - таблицы, ограничения, связи, индексы и представления.
- `sql/02_seed_data.sql` - карты, маршруты, точки построек, типы зомби, типы башен и состав волн.
- `sql/03_package_zombie_defense.sql` - PL/SQL-пакет `zombie_defense` с основной игровой логикой.
- `sql/04_grants.sql` - роль и права доступа для запуска игры другими пользователями Oracle.

## Установка базы данных

SQL-файлы нужно запускать в Oracle от имени схемы-владельца игры.

Ручной порядок запуска:

```sql
@sql/01_schema.sql
@sql/02_seed_data.sql
@sql/03_package_zombie_defense.sql
@sql/04_grants.sql
```

Также можно использовать общий файл:

```sql
@install.sql
```

Если используется SQL Developer или DBeaver, скрипты нужно запускать именно как SQL script, чтобы PL/SQL-блоки с `/` выполнились корректно.

## Настройка Python

Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

Задать параметры подключения к Oracle:

```powershell
$env:ZD_DB_DSN="localhost:1521/XEPDB1"
$env:ZD_DB_USER="ZD_OWNER"
$env:ZD_DB_PASSWORD="your_password"
```

Если Python подключается не под владельцем таблиц, нужно указать схему-владельца:

```powershell
$env:ZD_SCHEMA="ZD_OWNER"
```

## Запуск веб-игры

```powershell
python zombie_defense_web.py
```

По умолчанию сервер слушает:

```text
0.0.0.0:8000
```

На этом же компьютере игру можно открыть так:

```text
http://127.0.0.1:8000/
```

С телефона или другого компьютера в той же Wi-Fi сети нужно открыть IP компьютера, на котором запущен сервер:

```text
http://IP_КОМПЬЮТЕРА:8000/
```

Например:

```text
http://172.20.10.6:8000/
```

Если страница не открывается с другого устройства, нужно разрешить входящие подключения на порт `8000` в Windows Firewall.

## Как устроена игра

Браузер:

- показывает карту, башни, зомби, выстрелы и анимации;
- отправляет действия игрока на Python-сервер;
- периодически получает новое состояние игры.

Python:

- принимает HTTP-запросы;
- отдаёт HTML-страницы;
- получает действия игрока;
- вызывает процедуры PL/SQL;
- возвращает состояние игры в браузер.

Oracle PL/SQL:

- регистрирует игроков;
- запускает игровые сессии;
- создаёт волны;
- выпускает зомби;
- двигает зомби по маршруту;
- считает атаки башен;
- начисляет деньги;
- завершает игру победой или поражением;
- сохраняет историю и результаты.

## Возможности

- регистрация и вход игроков;
- выбор карты;
- несколько типов зомби;
- несколько типов башен;
- строительство, улучшение и снос башен;
- автоматические волны;
- плавная отрисовка движения;
- история игр;
- общий рейтинг игроков;
- фильтрация и сортировка результатов;
- игровые эффекты между пользователями: сладость и гадость;
- запуск в локальной сети, чтобы играть с телефона или другого компьютера.
